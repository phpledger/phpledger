PHP Ledger

PHP Ledger is open-source, self-hosted double-entry accounting software with core invoices, bills and payments, optional purchasing and inventory, and a manually configured tax engine. Built on PHP 8.2+ with MySQL 8.4 or MariaDB 10.4+, 1.1.2 is the current release: unzip it into any web folder, open it, and the browser installer starts; updates are publisher-signed. 1.0.0 was the first stable release; independent accounting and security review remain post-release commitments.

Current stable release: 1.1.2 (2026-09-20).
New project-owned code: AGPL-3.0-or-later; commercial licensing available. Pre-adoption 0.1.0 through 0.1.5 previews retain MIT; dependencies and archived code keep their own terms.

Read https://phpledger.com/llms.txt and https://phpledger.com/ai/summary.json.
Contact: https://github.com/phpledger/phpledger/discussions (public); security reports: https://github.com/phpledger/phpledger/blob/master/SECURITY.md. The public demo holds fictional sample data and resets hourly.
The static website has no analytics; the separate application has a documented optional country lookup.
