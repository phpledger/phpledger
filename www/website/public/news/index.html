Frequently asked questions

These answers describe the current release and the choices you need to make before evaluating it.

Where can I verify a release?

Use the GitHub release tag, downloadable ZIP and published SHA-256. The release notes identify the source and validation scope.

Does a news post upgrade my installation?

No. An operator must follow the matching UPGRADE.md, preserve a backup, rehearse restore and validate the target installation.

Are planned features included in the download?

Only capabilities explicitly marked implemented for that release are included. Research, roadmap items and schema foundations do not imply completed operator workflows.

How can I follow changes without an account?

Read this news page or subscribe to its RSS feed. The static website does not create an account or subscribe you to a mailing list.

What does a passing test suite prove?

It provides evidence for the tested technical cases and runtime. It does not establish accounting sign-off, regulatory compliance or success in every business workflow.
