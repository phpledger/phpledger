## Implemented behavior

| Workstream | Result | Boundaries |
| --- | --- | --- |
| Period close, reversals and cash counts | Audited required/advisory close checks; computed required blockers rechecked under the book lock; company attestations; synchronous scheduled reversals when a target period opens or a schedule enters an open period; immutable cash counts and centrally posted exact over/short differences. Pending schedules display their date, completed reversals display a linked result and no scheduling form. | No worker or year-end profit transfer. Stock-count confirmation is an attestation. Package checklist observations run before locks and are not atomic with closing. Foreign-currency designated cash accounts are rejected. |
| Employee master | Company-scoped identity, employment dates, effective-dated status, static salary references, immutable audit and an explicit same-company ownership-person link. `/employees` has restricted reads and writes, read-only detail and safe failed-form handling across company switches. | No payroll calculations, deductions, payslips or employee financial balances. Ordinary employee/trade links, duplicate-attribute reports and sales-staff/driver consolidation remain outside the saved M17 scope. Latest-record status may be future-dated; dated consumers use `pl_employee_status_at`. |
| Plugin secret storage | AES-256-GCM encryption with package/company/name scope binding, a private file key, fail-closed key errors, serialized key access, recoverable rotation and matched updater backup/restore. No plaintext browser interface. | In-process PHP plugins remain trusted code, not a sandbox. API version is now `1.1.0`; manifests declaring the exact previous `1.0.0` version must be updated and checked. No connector or provider credential was provisioned. |
