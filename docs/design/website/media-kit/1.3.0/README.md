# PHP Ledger 1.3.0 media kit

This kit contains factual announcement copy, social and email drafts, a guided demonstration and FAQs. Preparing or publishing the kit does not send a campaign. The project operator reviews links and publication status before using any draft.

PHP Ledger is open-source, self-hosted accounting for small businesses. Version 1.3.0 connects reviewed payroll, scheduling and year-end workflows to the same exact-money ledger used for invoices, bills, stock and reports. Its shared installer demo offers the real setup journey with disposable fictional records.

## Contents

- ANNOUNCEMENT.md: concise announcement and longer press copy.
- SOCIAL.md: short and long social drafts; never automatically posted.
- EMAIL.md: a draft invitation to try the release; never automatically sent.
- GUIDED-DEMO.md: shared installer, first transaction and feature tour.
- FAQ.md: hosting, feature boundaries, privacy and review status.
- screenshots/manifest.json: exact artifact provenance, original image hashes, routes, dimensions, captions and alt text, added by the release assembler.
- CHECKSUMS.txt: hashes for every included copy and screenshot file, excluding the checksum list itself.

## Use and attribution

Use the screenshots as captured.
