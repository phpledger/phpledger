# PHP Ledger 1.3.0: from daily books to a reviewed year end

## Short announcement

PHP Ledger 1.3.0 brings aggregate payroll accounting, reviewed recurring and loan drafts, confidential employee records, cash counts and fiscal-year close/reopen workflows to its self-hosted accounting application. These features use the same reviewed drafts, exact amounts and traceable posting controls as its invoices, bills, stock and reports.

Try the real browser installer in the shared hourly-reset demo, then install PHP Ledger on your own PHP hosting or use either official container registry. Optional multi-year sample histories are now separate validated data-only packages. The core retains its neutral starter.

## Press copy

PHP Ledger is an open-source, self-hosted accounting application for small businesses and the people who keep their books. Version 1.3.0 extends its daily accounting workflows into reviewed payroll, scheduling and financial close, while preserving one central posting service and immutable journal history.

Payroll accounting records reviewed aggregate accruals, staff advances, deductions and partial settlements. Personal employment information remains in a confidential register. Existing sales-staff and driver identities can be linked explicitly to employees without inventing hire dates or changing historical labels. Employment does not automatically designate a person as a related party.

Recurring, accrual and loan schedules prepare ordinary journal drafts for review. Loan schedules disclose their selected conventions. Period close includes a checklist and cash counts; fiscal-year close requires explicit legal treatment, destination accounts and any reviewed partnership ratios. Reversals and reopening retain traceable source relationships.

The release also supports installation-specific database table prefixes, explicit database TLS and MySQL 8.0.19 or newer, with MySQL 8.4 recommended. Arabic is available as a draft translation with right-to-left layout, pending native language and accounting review. Optional technical installation notices can be disabled without restricting the software; optional named registration is separate.

The public demo follows the actual installer and onboarding in one shared disposable installation. Database fields display labelled dummy values and cannot change host configuration. Visitors can join an installed demo with the public login demo / DemoLedger123!. All fictional records and PHP sessions are removed by the hourly reset. The host supplies verified read-only sample packages.

The official container channels are ghcr.io/phpledger/phpledger and phpledger/phpledger on Docker Hub. Both package the same verified application ZIP. Use the published receipt for the available tags, hashes and final validation results.

## Scope in the same announcement

Aggregate payroll accounting does not calculate per-person pay runs, produce payslips or file statutory returns. Loan conventions need review against the lender contract. Fictional industry samples are teaching material, not complete industry systems or compliance certifications. Independent accounting/security review, real-business acceptance and restricted-host recovery qualification remain separate gates. No claim of completed independent review or customer adoption is made.
