Pakistan pharmacy sample

v0.9.0-preview · sample data pack, not a plugin

UnverifiedNot installed

A fictional Pakistani pharmacy's chart of accounts, forms and a full transaction history, built to demonstrate the Pharmacy POS plugin during onboarding's Source stage. Also fictional and not yet built.

What it adds

  • Pharmacy chart of accounts
  • Batch/expiry item records
  • Sample transaction history

Requirements

  • Pharmacy POS plugin
  • PHP Ledger 1.2.0+
Offered on the onboarding Source stage once installed
Unverified code runs with this installation's full plugin permissions

No project key has signed either package. Installing asks for confirmation on a separate page, and updates never apply themselves — you click Update each time, after re-confirming (decision B51).

What "Verified" means here

Limited to packages signed by the PHP Ledger project key (decision B41), currently the seven bundled modules only. A directory plugin, however well reviewed, stays Unverified until that changes.

installation.admin is required to install or activate any package (decision B44).

Public demo

The Packages screen and plugin execution are both live in the public demo (decision B49). The demo's hourly reset and restricted grants apply to anything installed here — see ../DECISIONS.md for the open question on what visitors may install.
