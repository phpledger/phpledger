PHP bcmath is missing

bcmath is missing, and it is needed for exact money arithmetic — without it, PHP Ledger cannot guarantee that amounts add up exactly.

bcmath is now available — exact money arithmetic is back online.

Ways to fix this

1On XAMPP or Laragon: open php.ini, remove the semicolon before extension=bcmath, and restart Apache.
2On Ubuntu or Debian hosting: run sudo apt install php8.3-bcmath, then restart PHP-FPM.
3On shared hosting: open the PHP Selector or MultiPHP INI Editor in your control panel and enable bcmath.
We’ll only re-test this one thing.
