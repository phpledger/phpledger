Needs attention

PHP needs the bcmath extension.

PHP bcmath — missing, and it is needed for exact money arithmetic.

Ways to clear this

  1. Hosting control panel. Open “Select PHP Version” or “PHP Extensions” and turn bcmath on. Most hosts apply it within a minute — no restart needed.
  2. XAMPP or Laragon, on this computer. Open php.ini, remove the semicolon before extension=bcmath, save, then restart Apache from the control panel.
  3. No extensions screen? Ask your host to turn bcmath on for this account — it's a standard PHP extension every host can enable.

Connect your database.

On this computer, setup can create it for you — and root with no password is fine here.

It should match the address in your browser bar.

On this same computer, any name will do: setup creates it if it does not exist.

Leave the password empty only on this same computer, where XAMPP and Laragon install root without one. A database on another server always needs one.

A database server is answering on this computer at port 3306.

Where do I create the database?

XAMPP, Laragon or MAMP: nothing to prepare — leave the host as localhost and use root with no password.

cPanel and most hosts: open MySQL Databases, create a database and a user, then add the user with all privileges.

MySQL 8.4 and MariaDB 10.4 or newer both work. No terminal or Composer command is needed.
