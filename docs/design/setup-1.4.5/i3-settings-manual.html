?Explain Private settings file

Private settings file

It holds the database connection and this site's address. It sits outside public/, so a browser can never fetch it.

Setup writes it for you where the server allows. Here it could not, so you place the file once. Setup never overwrites an existing file.

Guide: file permissions on shared hosting

Setup keeps its settings in a private file outside the folder visitors can reach. This server refused to create it, so you place it once. Nothing else changes.

Place the file, then check again

  1. 1Choose Download private configuration. The file is named config.local.php and is complete.
  2. 2Open File Manager in cPanel or Plesk, go to phpledger/www/phpledger/includes/ and upload it there. Not inside public/.
  3. 3Right-click the file → Change permissions → 600 (owner may read and write, nobody else).
  4. 4Delete the downloaded copy from your computer, then choose I have placed it, check again.

Place the file, then check again

  1. 1Choose Download private configuration.
  2. 2Save it as C:\xampp\htdocs\phpledger\www\phpledger\includes\config.local.php. If Windows added .txt, remove it.
  3. 3If Windows refuses, right-click the includes folder → Properties → Security and allow your user to write, or start XAMPP as your own user.
  4. 4Choose I have placed it, check again.

Place the file, then check again

  1. 1Setup writes this file into the private data volume (PL_INSTALL_DIRECTORY). The volume is read-only or owned by another user.
  2. 2Give the volume back to the web server user, for example docker compose exec phpledger chown -R www-data:www-data /var/lib/phpledger/private, then check again.
  3. 3Or download the file and copy it in with docker cp config.local.php phpledger:/var/lib/phpledger/private/.
  4. 4Choose I have placed it, check again.
